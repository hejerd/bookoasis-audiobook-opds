# b3 검증 기록

- 수정 전: 새 재생 목록 테스트 5개가 실패했다. 첫 검증은 빈 회차 목록과 중간 회차 선택 실패를 재현했다(readest-playlist-before.log).
- 관련 회귀 테스트: 26개 파일, 291개 테스트 통과. 회차 전체 표시, 중간 파일만 측정, 불량인 뒤 회차가 첫 재생을 막지 않음, 기존 위치 변환, 로컬 인증 스트리밍 연결, 파일 선택 경합, 일시정지/자동 다음 회차, 기존 단일 파일/ABS/팟캐스트 화면을 검사했다.
- 마지막 취소 처리 변경 후 수정 파일 재검증: 5개 파일, 50개 테스트 통과(291개와 겹치는 테스트).
- TypeScript 검사 통과. Biome 전체 lint 2,849개 파일 통과.
- 전체 원본 테스트 실행은 통과하지 않았다. 사전 가져오기, 전자책 ZIP/이미지/텍스트 처리, TTS 문단, HTTP 테스트 등 변경 범위 밖에서 실패가 발생했고 Canvas 미지원 메시지 이후 수 분 동안 진행이 없어 종료했다. 전체 테스트 통과나 원본 전체 기능 무회귀를 주장하지 않는다. 전체 실행 로그를 별도로 보존했다.
- 실제 OpdsTracksView 컴포넌트를 앱의 내보낸 CSS로 번들한 브라우저 검증: 휴대폰 412×915, 태블릿 800×1100, 밝음/어두움/전자잉크/RTL에서 제목 줄바꿈과 목록 배치를 확인했다. 43개 샘플 중 20화를 검색하고 선택 번호가 20으로 바뀌는 것을 확인했다. 이 화면 검증용 환경은 실제 오디오를 재생하지 않는다.
- 연결된 Android 기기가 없어 b3 실기기 소리 출력, 잠금 화면/백그라운드 지속 재생, 실제 서버 첫 소리까지 걸리는 시간은 검증하지 못했다. 이전 b1의 실기기 재생 확인은 이번 b3의 재생 확인을 대신하지 않는다.
- BookOasis 운영 서버/DB/플러그인/포트는 이번 b3 작업에서 변경하지 않았다.

빌드·APK 서명·정렬·대응 소스 검사는 패키지 생성 후 validation의 JSON/로그에 기록한다.
