# Android 앱 설치와 연결

1. Android 8 이상 arm64-v8a 기기에서 [b7 APK](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b7/Readest-BookOasis-0.12.16-b7-arm64.apk)를 받습니다.
2. APK를 열어 **Readest BookOasis**를 설치합니다. 기존 BookOasis 앱은 **삭제하지 않고 업데이트**합니다. 공식 Readest와는 별도로 설치됩니다.
3. 서재의 **+ → 온라인 라이브러리(OPDS 카탈로그) → 내 카탈로그 → 카탈로그 추가**를 엽니다.
4. `http://서버주소:5941/opds` 또는 자신의 HTTPS OPDS 주소와 BookOasis 사용자 이름·비밀번호를 입력합니다. Google/Readest 로그인은 필요하지 않습니다.
5. 서버 → 카테고리 → 책을 열고 **재생**을 누릅니다. 여러 회차로 된 책은 표지·마지막 회차·저장 시간 아래의 **큰 ▶ 버튼**으로 이어 듣습니다. 처음 여는 책은 첫 회차부터 시작합니다.
6. 다른 회차부터 듣고 싶으면 **같은 화면 아래 회차 목록**에서 선택합니다. 재생 중에도 목록이 아래에 있으며, **회차 목록** 버튼을 누르면 목록 위치로 이동합니다.

플러그인 **0.5.2**와 함께 사용하세요. 이미 사용 중이라면 이번에는 앱만 업데이트하면 됩니다. 서버 포트는 **5941**을 유지합니다.

같은 BookOasis 서버·계정의 재생목록과 회차·위치를 자동 동기화합니다. 앱의 작은 동기화 아이콘에서 상태를 확인하며 따로 누를 필요는 없습니다. 웹에서 재생한 기록도 가져옵니다.

앱의 전체 진행률은 전체 회차에서의 현재 위치입니다. 회차 길이가 전부 확인되면 전체 시간과 남은 시간을 표시하며, 확인 전에는 회차 기준 근사값임을 표시합니다. 탐색 막대는 현재 회차 기준입니다.

기존 **b7-test1**과 이번 APK는 파일명이 달라도 내용과 서명이 같으므로, 테스트판을 설치했다면 재설치할 필요가 없습니다. 두 기기를 동시에 재생할 때는 마지막 저장 위치를 확인하세요.
