# Readest BookOasis b3 — 회차 목록과 선택 회차 재생

버전: 0.12.16+bookoasis.3 / Android versionCode 12018. 앱 ID com.bilingify.readest.bookoasis, Android 8 이상, arm64-v8a.

기존 b1/b2 앱을 삭제하지 않고 APK를 열어 업데이트한다. 같은 서명 인증서를 검사해 업데이트 파일을 만들었다. 공식 Readest 앱과는 별도 앱이다.

## 사용법

1. OPDS 카탈로그에서 여러 파일로 된 오디오북의 재생을 누른다.
2. 회차 목록이 먼저 열린다. 회차 이름으로 검색하거나 원하는 파일을 누른다. 중간 회차도 앞 회차 준비를 기다리지 않고 선택할 수 있다.
3. 재생 화면의 **회차 목록** 버튼으로 다른 회차를 선택한다. 현재 회차 표시와 준비 중 표시를 제공한다.
4. 이전/다음 버튼으로 파일을 이동한다. 회차가 끝나면 다음 회차를 자동으로 준비하고 재생한다. 챕터 끝에서 정지 타이머는 다음 회차에서 일시정지한다.
5. 다시 열면 **재개** 버튼으로 마지막 회차의 저장된 위치에서 이어듣는다.

재생 시간과 탐색 막대는 현재 파일 기준이다. 서재의 진행률은 완료한 회차 수와 현재 회차 내 비율을 기준으로 계산한다. 회차마다 길이가 다르면 전체 재생 시간의 비율과 다를 수 있다.

이전 b1/b2의 전체 시간 기준 위치는 '재개'를 누를 때 현재 회차까지 길이를 읽어 한 번 변환한다. 이 최초 변환에는 대기가 있을 수 있다. 회차를 직접 선택하면 변환을 기다리지 않는다. 변환 후부터는 회차 URL과 파일 내 시간을 저장한다.

## 대기 시간 변경과 한계

기존에는 전체 회차 길이를 모두 확인한 뒤 플레이어를 열었다. b3는 목록 표시에는 오디오 요청을 하지 않고, 선택한 회차의 길이만 확인한다. 파일 전체를 합치지 않는다.

기본 인증만 사용하는 네이티브 앱의 같은 서버 트랙은 앱에 이미 내장된 localhost Range 스트리밍 경로를 사용한다. 인증 헤더는 네이티브 HTTP 클라이언트가 서버에 보내며 URL에 비밀번호를 넣지 않는다. 별도 사용자 헤더가 있거나 로컬 스트리밍 경로를 사용할 수 없는 환경은 기존 현재 파일 Blob 방식으로 대체되므로 대기가 남을 수 있다. 공개 웹 앱의 인증된 오디오 제한은 유지한다.

실제 휴대폰에서 재생과 지연 시간은 이번 b3에서 검증하지 못했다. 단위/화면/빌드 검증 범위는 VALIDATION.ko.md에 기록한다. 서버 파일이 사라진 오디오북은 이 앱 변경으로 복구되지 않는다.
