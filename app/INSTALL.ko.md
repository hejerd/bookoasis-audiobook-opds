# Android에서 BookOasis 오디오북 듣기

**Readest BookOasis**는 `audiobook_opds` 플러그인이 설치된 BookOasis 서버에 연결하는 Android 클라이언트 앱입니다. Readest를 수정한 비공식 앱이며, 서버 플러그인과 함께 사용합니다.

아직 서버에 플러그인을 설치하지 않았다면 [서버 설치 안내](../docs/INSTALL.ko.md)를 먼저 진행하세요.

## 1. 앱 설치

1. [다운로드 페이지](https://github.com/hejerd/bookoasis-audiobook-opds/releases)에서 `Readest-BookOasis-…-arm64.apk`를 받습니다.
2. 휴대폰·태블릿에서 APK를 엽니다.
3. Android가 설치 허용을 요청하면 파일을 연 브라우저·파일 앱에 허용하고 설치를 진행합니다.
4. 설치된 **Readest BookOasis** 앱을 실행합니다.

지원 기기는 Android 8 이상, arm64-v8a입니다. 공식 Readest와 앱 이름·앱 ID가 달라 함께 설치할 수 있습니다. 기존 Readest BookOasis가 설치되어 있다면 삭제하지 않고 새 APK를 열어 업데이트합니다.

## 2. OPDS 카탈로그 추가

1. 서재 위쪽 **`+`**를 누릅니다.
2. **온라인 라이브러리**를 엽니다. 기기에 따라 **OPDS 카탈로그**로 표시될 수 있습니다.
3. **내 카탈로그** 옆의 **카탈로그 추가**를 누릅니다.
4. 아래 항목을 입력하고 **카탈로그 추가**를 누릅니다.

| 항목 | 입력할 내용 |
| --- | --- |
| 카탈로그 이름 | 원하는 이름. 예: `내 BookOasis 오디오북` |
| OPDS URL | `http://서버주소:5941/opds` 또는 설정한 외부 HTTPS 주소 |
| 사용자 이름 | 기존 BookOasis 로그인 사용자 이름 |
| 비밀번호 | 해당 BookOasis 계정의 비밀번호 |

같은 네트워크 안에서 서버 주소가 `192.168.1.10`인 예시는 `http://192.168.1.10:5941/opds`입니다. 외부 HTTPS 프록시를 설정했다면 `https://audio.example.com/opds` 형태를 사용합니다. 예시 주소는 실제 주소로 바꾸세요.

사용자 이름·비밀번호가 화면에 선택 사항으로 표시되어도 이 서버 연결에는 둘 다 필요합니다. **BookOasis 계정**을 입력하며, OPDS 연결을 위해 Readest 계정이나 Google로 로그인할 필요는 없습니다.

## 3. 책과 회차 선택

1. **내 카탈로그**에서 등록한 서버 이름을 누릅니다.
2. 첫 화면에서 카테고리를 선택합니다.
3. 표지와 아래 제목을 보고 책을 고릅니다.
4. 책 상세 화면의 **재생**을 누릅니다.
5. 여러 회차로 된 책은 회차 목록이 열립니다. 듣고 싶은 회차를 누릅니다. 한 파일로 된 책은 플레이어로 이동합니다.

회차 이름으로 검색할 수 있고 중간 회차부터 선택해도 됩니다. 재생 중 **회차 목록** 버튼으로 다시 목록을 열거나 이전·다음 버튼으로 회차를 옮깁니다. 회차가 끝나면 다음 회차로 넘어갑니다.

## 4. 정렬과 검색

카테고리 안의 정렬 메뉴에서 다음 중 하나를 선택합니다. 작은 화면에서는 필터 메뉴에 표시될 수 있습니다.

- 제목 가나다순
- 제목 역순
- 최신 추가순
- 오래된 추가순
- 최근 수정순

카테고리 안에서 제목을 검색하면 해당 카테고리의 책을 찾습니다. 목록을 새로 받으려면 현재 카탈로그 화면을 닫고 **내 카탈로그**에서 다시 엽니다.

## 5. 이어듣기

책을 다시 열면 **재개**로 마지막 회차의 저장된 위치에서 이어듣습니다. 다른 회차를 원하면 목록에서 직접 선택합니다.

재생 시간과 탐색 막대는 **현재 회차** 기준입니다. BookOasis 웹 플레이어와 이 앱 사이의 재생 위치 동기화는 지원하지 않습니다.

## 연결과 재생이 안 될 때

| 증상 | 확인할 내용 |
| --- | --- |
| 카탈로그 추가 실패 | 휴대폰 브라우저에서 같은 OPDS URL을 열어 연결과 계정 확인 |
| 집에서는 되는데 외부에서 실패 | 내부 IP는 집 밖에서 접속되지 않음. 서버의 외부 HTTPS 주소와 프록시 연결 확인 |
| 목록이 비어 있음 | BookOasis에 오디오북이 등록되어 있는지, 계정에 라이브러리 접근 권한이 있는지 확인 |
| 재생 버튼이 없거나 재생 실패 | Readest BookOasis 앱인지 확인. 서버 원본 음원 경로·파일도 확인 |
| 첫 재생까지 대기 | 회차 목록에서 원하는 회차를 직접 선택. 원격 드라이브 응답 속도에 따라 준비 시간이 걸릴 수 있음 |
| 표지·정렬이 예전 모습 | 서버 플러그인을 업데이트한 뒤 카탈로그를 닫고 다시 열기 |
| APK 설치 불가 | Android 8 이상, arm64-v8a 기기인지 확인. 공식 Readest 대신 별도 앱인 Readest BookOasis APK 사용 |
