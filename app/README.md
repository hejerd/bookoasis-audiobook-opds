# Readest BookOasis b7

Readest 기반 비공식 오디오북 클라이언트입니다. Android 8 이상, arm64-v8a용이며 앱 ID는 `com.bilingify.readest.bookoasis`입니다.

b7은 표지·마지막 청취 위치·큰 ▶ 버튼·회차 목록을 한 화면에 배치합니다. 큰 ▶ 버튼은 저장 위치에서 이어 듣고, 아래 목록에서는 원하는 회차를 바로 고를 수 있습니다. 재생 중에도 목록을 같은 화면에서 이용합니다.

BookOasis 서버 자동 동기화와 전체 진행률은 계속 제공합니다. 서버 플러그인 0.5.2, 기본 포트 5941을 사용합니다.
