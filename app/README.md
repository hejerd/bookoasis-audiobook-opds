# Readest BookOasis b6

Readest 0.12.16 기반의 비공식 오디오북 클라이언트입니다. Android 8 이상, arm64-v8a용이며 앱 ID는 `com.bilingify.readest.bookoasis`입니다.

b6는 회차 목록·표지 그리드에 더해 BookOasis 서버 자동 동기화, 작은 상태 아이콘, 전체 회차 진행률·남은 시간을 제공합니다. BookOasis OPDS 재생목록과 위치는 사용자의 BookOasis 서버에 저장합니다.

[설치](INSTALL.ko.md) · [검증](VALIDATION.ko.md) · [빌드](BUILD-b6.ko.md) · [전체 대응 소스](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b6/Readest-BookOasis-0.12.16-b6-source.zip)

같은 이름의 b6-test1 APK와 바이트가 동일합니다. 기존 b3 자료와 패치는 이전 버전의 기록입니다. 현재 버전의 전체 소스와 고정 하위 모듈은 b6 소스 ZIP을 사용하세요.
