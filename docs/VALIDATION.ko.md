# 플러그인 0.5.2 검증 결과

0.5.2-test1에서 검증한 런타임 소스를 그대로 사용하고 VERSION만 0.5.2로 변경했습니다.

- 공식 BookOasis DB 스키마·gateway와 임시 SQLite DB: **209개 통과, 선택 실행 브라우저 검사 2개 생략**, 192.79초.
- 설치된 서버 이미지의 임시 DB: 실제 위젯 HTTP API·UI 번들 로더·인증/접근 권한·기존 동기화 등 **17개 확인 통과**.
- 실제 위젯 HTML/CSS/JS를 휴대폰 폭 390px로 렌더링하고 새로고침 확인.
- 설치 전후 본체 관련 파일 9개의 SHA256이 일치했습니다. 본체 소스와 DB 구조를 변경하지 않습니다.
- 동기화 검사: 앱/웹 양방향 위치, 사용자별 분리, 접근 권한, 오래된 revision 거부, 재시도와 중단 후 복구, 웹 기록의 목록 가져오기.
- 진행률: 전체 길이를 알면 시간 기준, 일부 길이가 없으면 회차 기준 근사값, 현재 회차 길이도 없으면 임의 %를 만들지 않음.

본체의 기존 독서 인사이트 ‘현재 읽는 중’ 카드는 별개이므로 잘못된 98% 표시가 남을 수 있습니다. 새 **오디오북 청취 진행률** 위젯에서 확인하세요. MariaDB 실기와 모든 Android 기기 검증은 수행하지 않았습니다.
