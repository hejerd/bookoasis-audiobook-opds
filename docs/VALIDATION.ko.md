# 0.4.1 표지 그리드 검증 — 2026-10-24

책 목록은 표지를 포함해도 acquisition 링크가 없어 Readest parser에서 navigation으로 분류되었다. 현재 Readest의 실제 PublicationCard에는 이미 표지와 아래 제목이 구현되어 있었다. 앱을 바꾸지 않고 플러그인의 책 목록을 acquisition feed로 변경했다.

- 로컬 최종 결과 172개 통과: 초기 171개 통과 + 기존 navigation 기대를 acquisition으로 바꾼 계약 검사 1개 재실행 통과. 초기 실패 기록은 개발 검증 기록에 별도로 보존했다.
- 변경 전 신규 회귀 검사 8개 중 5개 실패, 수정 후 8개 통과.
- 기존 Readest parser에서 표지 카드 30권, 회차 링크 178개, 카테고리 navigation 및 정렬 5개 확인.
- 실제 서버 DB의 450권에 대해 책 목록과 상세의 전체 회차 링크가 동일함을 확인. 14개 카테고리 + 전체 범위의 정렬 75개 검사 통과. 운영 계정의 자격 증명 대신 임시 general DB 계정을 사용했다. 실제 audiobook DB·미디어는 읽기 전용 Docker 마운트다.
- 서버 내부에서 30권 목록 응답 약 80~153ms. XML은 카테고리별 약 45~745KB(전체 회차 링크 포함). 표지 다운로드·외부 네트워크·Android 렌더링 시간을 포함하지 않는다.
- 실제 표지 3개 HTTP 200 및 이미지 디코딩 정상. 기존 실제 음원 2개의 HEAD 200·Range 206(각 1024바이트) 정상.
- 실제 Readest 목록 컴포넌트의 브라우저 화면에서 표지 그리드·아래 제목과 올바른 책 선택 확인.

회차 정보는 보이는 페이지의 허용된 책 ID만 묶어 한 번에 조회한다. 음원을 열거나 전체 파일을 내려받거나 길이를 측정하는 작업은 목록 조회에 없다. 기존 인증·서재 권한·숨김 표지·다운로드 권한·정렬·카테고리·페이지 이동을 유지한다.

Android 실기 재생 및 네트워크별 표시 속도는 이번 검사에 포함하지 않았다. MariaDB 실기 검증은 수행하지 않았다.
