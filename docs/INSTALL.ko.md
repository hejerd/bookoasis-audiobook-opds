# audiobook_opds 0.4.1 설치·업데이트

책 목록을 표지 그리드로 표시하는 플러그인 패키지다. 기존 Readest APK를 다시 설치할 필요가 없다. 카테고리는 기존 메뉴, 카테고리 안의 책은 표지와 아래 제목으로 표시된다.

## 기존 0.4.0에서 업데이트

1. 기존 플러그인과 DB·설정·Compose를 백업한다. SQLite는 정상적인 online backup API 또는 정지 상태의 DB/WAL 백업을 사용한다.
2. 컨테이너 `bookoasis`를 정지한다.
3. `/path/to/BookOasis_stable/plugins/metadata/audiobook_opds`의 이전 코드를 `metadata` 밖에 보관한다. 백업 폴더를 로더가 다른 플러그인으로 읽지 않게 한다.
4. ZIP의 `plugins/metadata/audiobook_opds/` 폴더를 해당 위치에 복사한다. VERSION은 0.4.1이다. 다른 플러그인을 덮어쓰지 않는다.
5. 컨테이너를 시작한다. 기존 5930·5931 매핑을 유지한다. OS 재부팅은 필요 없다.
6. 대시보드·OPDS 응답을 확인한다. Readest의 OPDS 카탈로그 화면을 닫고 다시 열어 카테고리를 선택한다. 표지와 아래 제목이 나타난다. 정렬 5종과 기존 회차 재생을 계속 사용한다.

DB 스키마·계정·미디어·포트·앱 ID·카탈로그 URL은 변경하지 않는다. 이미 5931 매핑이 있으면 Compose 변경은 필요 없다.

## 신규 설치

플러그인 ID는 `audiobook_opds`다. general 관리자 설정에서 활성화 토글과 OPDS 서비스 시작을 켠다. 기본 bind_host=0.0.0.0, port=5931, page_size=30. public_base_url은 비우면 요청 주소를 사용한다. 프록시 기본 URL에는 끝에 /opds를 붙이지 않는다.

Compose의 기존 옵션을 보존하고 `5931:5931`을 추가한다. 새로운 포트 매핑에는 컨테이너 재생성이 필요하다. OPDS URL은 `http://서버주소:5931/opds`, 인증은 기존 BookOasis 사용자명·비밀번호다. 기존 라이브러리 접근 권한을 적용한다. 외부 접속용 HTTPS 프록시는 운영 환경에 맞춰 설정한다.

## 되돌리기

컨테이너를 정지하고 0.4.1 폴더를 metadata 밖으로 옮긴 뒤 보관한 0.4.0 코드를 원래 위치로 복구하고 시작한다. 코드 업데이트 롤백에는 DB 전체 복원이 필요 없다. 앱 삭제나 재생 기록 삭제도 필요 없다.
