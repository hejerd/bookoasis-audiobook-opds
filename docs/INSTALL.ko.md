# BookOasis 서버에 플러그인 설치하기

`audiobook_opds`는 기존 BookOasis 서버에 추가해 오디오북 클라이언트 앱을 연결하는 플러그인입니다. 이 안내는 BookOasis가 이미 실행 중이고 오디오북이 등록된 서버를 기준으로 합니다.

설치 순서는 **플러그인게시판에서 Git URL 설치 → Docker 포트 추가 → BookOasis 재시작 → OPDS 서비스 켜기**입니다. 이후 [Android 앱 연결](../app/INSTALL.ko.md)을 진행합니다. 플러그인게시판이 없다면 ZIP으로 수동 설치할 수 있습니다.

## 1. 플러그인 파일 넣기

### 플러그인게시판에서 Git URL로 설치

1. **플러그인게시판 → Git 저장소 URL 설치**에 `https://github.com/hejerd/bookoasis-audiobook-opds`를 입력합니다.
2. **Git 설치**를 누릅니다. 설치된 플러그인 이름은 **오디오북 OPDS**, 폴더와 ID는 `audiobook_opds`입니다.
3. **2. Docker 포트 5941 추가**부터 계속합니다. 설치 버튼은 Docker 포트를 변경하지 않습니다.

설치 후 업데이트는 플러그인게시판에서 진행합니다. 기존에 파일을 복사해 설치했어도 클래스 ID가 같은 `audiobook_opds` 폴더를 찾아 사용합니다. 설치 이력에 다른 저장소가 같은 폴더를 사용 중이라고 나오면 먼저 주소와 폴더를 확인하세요.

### ZIP으로 수동 설치

1. 릴리스의 [audiobook_opds-0.5.2.zip](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b6/audiobook_opds-0.5.2.zip)을 다운로드해 압축을 풉니다.
2. 압축 안에서 `plugins/metadata/audiobook_opds` 폴더를 찾습니다.
3. 이 `audiobook_opds` 폴더를 서버의 BookOasis 플러그인 폴더 아래 `metadata` 안에 넣습니다.

Docker에서는 기존 `/app/plugins` 마운트의 **서버 쪽 경로**를 사용합니다. Compose의 `volumes`에서 확인할 수 있습니다.

```yaml
volumes:
  - ./plugins:/app/plugins
```

위 설정이라면 Compose 파일 옆의 `plugins/metadata/audiobook_opds/`가 설치 위치입니다. 절대 경로가 지정되어 있다면 그 경로의 `metadata` 안에 넣습니다.

최종 구성은 다음과 같습니다.

```text
plugins/
└── metadata/
    └── audiobook_opds/
        ├── __init__.py
        ├── audiobook_opds.py
        ├── VERSION
        ├── dashboard.html
        ├── dashboard.css
        └── dashboard.js
```

릴리스 ZIP에서는 그 안의 **`audiobook_opds` 폴더 하나**를 복사합니다. GitHub의 **Code → Download ZIP**은 저장소 최상위에 플러그인 파일이 있는 구조입니다. 이 파일을 사용한다면 `audiobook_opds` 폴더를 직접 만들고 그 안에 `__init__.py`, `audiobook_opds.py`, `VERSION`, `dashboard.html`, `dashboard.css`, `dashboard.js` 여섯 파일과 `LICENSE`를 넣으세요.

## 2. Docker 포트 5941 추가

이 플러그인은 기존 BookOasis 프로세스 안에서 OPDS 서비스를 시작하며, 클라이언트 접속에는 별도 포트 **5941**을 사용합니다.

`docker-compose.yml`에서 BookOasis 서비스의 기존 `ports` 목록에 다음 한 줄을 추가하세요.

```yaml
- "5941:5941"
```

앞의 `5941`은 서버에서 접속할 포트, 뒤의 `5941`은 컨테이너 내부 포트입니다. 기존 웹 화면 포트, 마운트, 환경 변수는 유지합니다.

Compose 파일이 있는 폴더에서 실행합니다. 아래 예시의 서비스 이름은 `bookoasis`이며, 다르게 지정했다면 그 이름을 사용합니다.

```bash
docker compose up -d bookoasis
```

포트 설정이 바뀌면 Compose가 컨테이너를 새 설정으로 재생성합니다. 단순 `docker restart`만으로는 새 포트 매핑이 적용되지 않습니다.

**이미 `5941:5941`이 설정되어 있다면** 파일 복사 후 다음과 같이 컨테이너만 재시작합니다. 여기서 `bookoasis`는 컨테이너 이름입니다.

```bash
docker restart bookoasis
```

NAS나 Docker 관리 화면을 사용한다면 같은 의미로 컨테이너의 TCP 포트 `5941`을 서버 포트 `5941`에 연결한 뒤 변경 사항을 적용합니다. 서버 OS 재부팅은 필요 없습니다.

## 3. BookOasis에서 서비스 켜기

1. 관리자 계정으로 BookOasis에 로그인합니다.
2. **일반 도서 → 환경설정 → 플러그인 설정**을 엽니다.
3. **오디오북 OPDS**의 활성화 스위치를 켭니다.
4. **OPDS 서비스 시작 → 사용**을 체크합니다.
5. 아래 설정을 확인하고 **설정 저장**을 누릅니다.

| 항목 | 권장 시작값 | 설명 |
| --- | --- | --- |
| 수신 주소 | `0.0.0.0` | Docker로 게시한 포트에서 요청을 받음 |
| 컨테이너 내부 포트 | `5941` | Docker 매핑의 뒤쪽 포트와 맞춤 |
| 앱에서 접속할 기본 URL | 빈칸 | 처음에는 요청받은 주소를 사용 |
| 페이지당 목록 항목 수 | `30` | 한 페이지에 표시할 수 |
| 카탈로그 제목 | `BookOasis Audiobooks` | 앱에 표시될 카탈로그 제목 |

설정 화면에 **오디오북 OPDS**가 없다면 플러그인 경로와 파일 이름을 확인하고 BookOasis를 재시작합니다.

## 4. 연결 확인

휴대폰을 서버와 같은 네트워크에 연결하고, 휴대폰 브라우저에서 다음 주소를 엽니다.

```text
http://서버주소:5941/opds
```

예시 서버 주소가 `192.168.1.10`이면 `http://192.168.1.10:5941/opds`입니다. 예시 주소는 실제 서버 주소로 바꿔 입력합니다. 수신 주소인 `0.0.0.0`을 앱 접속 주소로 입력하지 않습니다.

계정 입력창이 나오면 기존 BookOasis 사용자 이름과 비밀번호를 입력합니다. 인증 후 XML 목록이 보이면 정상입니다. 브라우저는 연결 확인용이고, 실제 책 탐색·재생은 [Readest BookOasis 앱](../app/INSTALL.ko.md)에서 합니다.

BookOasis 계정의 오디오북 접근 권한과 라이브러리 접근 권한이 적용됩니다. 기본 비밀번호 상태인 계정은 먼저 BookOasis에서 비밀번호를 변경하세요.

## 외부에서 접속하기

집 밖에서는 내부 IP 대신 외부에서 접근 가능한 주소를 사용합니다. HTTPS 리버스 프록시를 사용하는 경우 예시는 다음과 같습니다.

| 위치 | 설정 예시 |
| --- | --- |
| 프록시의 외부 주소 | `https://audio.example.com` |
| 프록시의 연결 대상 | BookOasis 서버의 `5941` 포트 |
| 플러그인의 앱에서 접속할 기본 URL | `https://audio.example.com` |
| 앱의 OPDS URL | `https://audio.example.com/opds` |

기본 URL 설정에는 `/opds`를 붙이지 않고, 앱의 OPDS URL에는 붙입니다. `example.com`은 예시이므로 자신의 도메인으로 바꿉니다. 외부 접속을 위해 별도 VPN이 필수인 것은 아닙니다. 기존 BookOasis 웹 화면이 외부에서 열린다는 것만으로 OPDS의 5941 포트까지 연결되는 것은 아니므로, OPDS용 프록시 경로를 추가해야 합니다.

## 업데이트

### 기존 5931에서 5941로 옮기기

0.4.2부터 신규 설치 기본 포트는 **5941**입니다. 이미 저장된 **5931은 업데이트만으로 바뀌지 않습니다.** 사용 중인 주소를 옮기려면 다음을 함께 적용합니다.

1. Git URL 설치 또는 업데이트로 최신 플러그인을 적용합니다.
2. **오디오북 OPDS 설정 → 컨테이너 내부 포트**를 `5941`로 바꾸고 저장합니다.
3. Docker의 `ports`에 `5941:5941`을 추가합니다. `5931:5931`을 다른 플러그인이 사용한다면 그 매핑은 유지합니다.
4. Compose 파일이 있는 폴더에서 `docker compose up -d bookoasis`로 적용합니다. 서비스 이름이 다르면 실제 이름을 사용합니다.
5. 앱의 OPDS URL을 `http://서버주소:5941/opds`로 바꿉니다. 외부 HTTPS 주소가 같다면 프록시 연결 대상만 서버의 `5941`로 변경합니다. 플러그인의 기본 URL에 이전 포트가 들어 있다면 그 값도 바꿉니다.

서버 OS를 재부팅하거나 Android APK를 다시 설치할 필요는 없습니다. 5941이 이미 사용 중이라면 서버에서 비어 있는 다른 포트를 선택할 수 있습니다.

### 일반 업데이트

**Git URL로 설치했다면:** 플러그인게시판의 오디오북 OPDS 카드에서 **업데이트**를 누릅니다. 코드 반영 후 BookOasis 컨테이너를 재시작해 OPDS 백그라운드 서비스도 새 코드로 시작하세요. 기존 포트와 설정은 그대로 사용합니다.

**ZIP으로 수동 설치했다면:**

1. 기존 `audiobook_opds` 폴더를 보관해 두면 필요할 때 이전 버전으로 돌아갈 수 있습니다. 보관본은 `plugins/metadata` 밖에 둡니다.
2. 새 버전의 `audiobook_opds` 폴더로 교체합니다.
3. BookOasis 컨테이너를 재시작합니다. 5941 매핑과 저장한 플러그인 설정은 그대로 사용합니다.
4. 앱의 카탈로그 화면을 닫고 다시 엽니다.

이 플러그인은 기존 DB 구조를 변환하거나 미디어를 옮기지 않습니다. 동기화 기능은 계정별 재생목록·위치와 BookOasis의 기존 청취 기록을 저장합니다. 신규 설치를 위해 DB 전체 백업·복원이 필요한 것은 아닙니다.

## 동기화와 웹 진행률 위젯

앱 b6를 함께 설치하고 같은 OPDS 서버·계정으로 접속하세요. 별도 동기화 버튼은 필요하지 않습니다.

웹 위젯은 다음 순서로 추가합니다.

1. **환경설정 → 내 설정** 맨 아래의 **홈 화면을 플러그인 배치 모드로 전환**을 체크하고 **설정 저장**을 누릅니다.
2. **오디오북 홈**으로 돌아가 맨 아래까지 스크롤합니다.
3. 마지막 위젯 아래, 저작권 문구 위 **오른쪽의 🔒 배치 잠금**을 누릅니다. **배치 편집 중**으로 바뀌어야 합니다.
4. 그 아래 나타난 **+ 위젯 추가:**에서 **오디오북 청취 진행률** 버튼을 누릅니다. 배치는 자동 저장됩니다.
5. 원하는 위치로 드래그한 뒤 **배치 편집 중**을 다시 눌러 잠급니다.

잠금 상태에서는 추가 메뉴가 숨겨집니다. 이미 홈에 추가한 위젯은 추가 목록에 나오지 않으므로 홈 화면을 먼저 확인하세요. 이 위젯은 오디오북 홈에서만 제공합니다.

기존 ‘현재 읽는 중’ 카드의 계산식은 변경되지 않습니다. [버튼 위치와 문제 해결](../README.md#7-웹-홈에-진행률-위젯-추가)을 확인하세요.

## 사용 중지와 제거

사용을 멈추려면 설정에서 **OPDS 서비스 시작 → 사용**을 끄고 저장합니다. 완전히 제거하려면 `audiobook_opds` 폴더를 `plugins/metadata` 밖으로 옮기고 BookOasis를 재시작합니다. 다른 용도로 쓰지 않는다면 Docker의 `5941:5941` 매핑도 제거할 수 있습니다. 기존 오디오북과 계정은 계속 BookOasis에서 사용합니다.

## 문제 해결

| 증상 | 해결 방법 |
| --- | --- |
| 플러그인이 목록에 없음 | 폴더 중첩, `audiobook_opds.py`·`__init__.py`·`VERSION` 확인 후 재시작 |
| 연결 거부·시간 초과 | OPDS 서비스 사용 체크, 수신 주소 `0.0.0.0`, 포트 매핑, 방화벽·네트워크 확인 |
| 5941 포트 사용 중 오류 | 서버 쪽 포트 충돌이면 `5942:5941`로 매핑하고 앱 주소를 `:5942/opds`로 변경. 컨테이너 안에서도 충돌하면 플러그인 내부 포트와 매핑 뒤쪽 포트도 함께 변경 |
| 인증 오류 | 웹 화면에서 같은 계정으로 로그인되는지 확인. 기본 비밀번호 상태면 변경 |
| 카테고리·책이 없음 | 오디오북 등록·스캔 상태와 해당 계정의 라이브러리 권한 확인 |
| 목록은 보이지만 재생 실패 | 서버에서 해당 음원 경로와 파일을 읽을 수 있는지, MP3·M4A·M4B인지 확인 |
| 다운로드만 거부됨 | 해당 BookOasis 계정의 다운로드 권한 확인 |
