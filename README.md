# BookOasis 오디오북 클라이언트 연결 플러그인

**기존 BookOasis 서버에 추가해, 오디오북 클라이언트 앱에서 서버의 책을 찾아 듣게 해주는 플러그인입니다.**

서버에는 `audiobook_opds` 플러그인을 설치하고, Android 휴대폰·태블릿에는 **Readest BookOasis** 앱을 설치합니다. 앱에 서버의 OPDS 주소와 BookOasis 계정을 등록하면 연결됩니다.

**BookOasis 서버 → audiobook_opds 플러그인 → Readest BookOasis 앱 → 오디오북 재생**

> **현재 버전: 플러그인 0.5.2 · 앱 b6 · 기본 포트 5941**
>
> Docker에는 `5941:5941`, 앱에는 `http://서버주소:5941/opds`를 사용합니다. 기존 5931 설정은 업데이트만으로 바뀌지 않으므로 플러그인 내부 포트·Docker 매핑·앱 주소 또는 프록시 연결 대상을 함께 변경하세요. 다른 플러그인이 사용하는 5931 매핑은 유지합니다. [기존 설치 전환 방법](docs/INSTALL.ko.md#기존-5931에서-5941로-옮기기)
>
> 자동 동기화와 전체 진행률을 사용하려면 아래 b6 APK로 업데이트하세요. 기존 앱을 삭제할 필요는 없습니다.

## 할 수 있는 것

- BookOasis에 등록된 오디오북을 카테고리별로 탐색
- 표지와 제목을 그리드로 표시하고 제목순·최신 추가순 등으로 정렬
- 책을 열어 회차 목록에서 원하는 회차 선택
- 이어듣기, 이전·다음 회차 이동, 다음 회차 자동 재생
- MP3·M4A·M4B 스트리밍과 다운로드
- 내 BookOasis 서버에 재생목록·현재 회차·재생 위치 자동 동기화
- 앱과 BookOasis 웹 사이 이어듣기, 전체 회차 진행률·남은 시간 표시
- 웹 홈에 추가할 수 있는 **오디오북 청취 진행률** 위젯

기존 BookOasis 계정과 라이브러리 접근 권한을 사용합니다. Readest BookOasis는 이 연결에 맞춰 수정한 **비공식 Android 앱**이며, 공식 Readest와 별도로 설치됩니다.

## 1. 서버에 플러그인 설치

### 플러그인게시판에서 Git URL로 설치

1. BookOasis의 **플러그인게시판 → Git 저장소 URL 설치**에 다음 주소를 붙여넣습니다.

   ```text
   https://github.com/hejerd/bookoasis-audiobook-opds
   ```

2. **Git 설치**를 누릅니다. 저장소 이름과 관계없이 플러그인은 `audiobook_opds` 폴더에 설치됩니다.
3. 아래의 **Docker 포트 추가**와 **BookOasis에서 서비스 켜기**를 진행합니다. 플러그인게시판에서 설치해도 Docker 포트는 별도로 추가해야 합니다.

공개 저장소이므로 GitHub 토큰은 필수가 아닙니다. 이후 플러그인게시판에서 업데이트할 수 있습니다. 이 방식은 플러그인게시판 2.52.0의 설치 소스를 기준으로 검사했습니다.

### ZIP으로 수동 설치하는 경우

1. **[플러그인 ZIP 다운로드](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b6/audiobook_opds-0.5.2.zip)** 후 압축을 풉니다.
2. 압축 안의 `plugins/metadata/audiobook_opds` 폴더를 서버의 BookOasis 플러그인 폴더에 복사합니다.
3. 최종 파일 위치가 아래와 같으면 됩니다. `audiobook_opds` 폴더가 두 번 중첩되지 않도록 확인하세요.

```text
BookOasis 플러그인 폴더/
└── metadata/
    └── audiobook_opds/
        ├── __init__.py
        ├── audiobook_opds.py
        ├── VERSION
        ├── dashboard.html
        ├── dashboard.css
        └── dashboard.js
```

Docker를 사용한다면 컨테이너의 `/app/plugins`에 연결된 **서버 쪽 폴더**에 넣습니다. [폴더 위치 확인 방법](docs/INSTALL.ko.md#1-플러그인-파일-넣기)

### Docker 포트 추가

이 플러그인은 OPDS 연결에 기본적으로 **5941 포트**를 사용합니다. 기존 BookOasis 웹 화면 포트와 함께 사용할 수 있도록 `docker-compose.yml`의 BookOasis 서비스 `ports` 목록에 다음 한 줄을 추가합니다.

```yaml
- "5941:5941"
```

기존 포트·볼륨·환경 변수는 그대로 두고, Compose 파일이 있는 폴더에서 다음을 실행합니다. 예시 서비스 이름은 `bookoasis`입니다.

```bash
docker compose up -d bookoasis
```

이미 `5941:5941`이 설정되어 있다면 파일 복사 후 BookOasis 컨테이너만 재시작하면 됩니다. **서버 OS를 재부팅할 필요는 없습니다.**

기존에 5931로 사용했다면 업데이트 후에도 저장된 값은 유지됩니다. 포트를 옮기려면 [5931에서 5941로 전환](docs/INSTALL.ko.md#기존-5931에서-5941로-옮기기)을 따라 설정과 매핑을 함께 바꿉니다.

## 2. BookOasis에서 서비스 켜기

1. BookOasis에 **관리자 계정**으로 접속합니다.
2. **일반 도서 → 환경설정 → 플러그인 설정**에서 **오디오북 OPDS**를 찾습니다.
3. 플러그인 활성화 스위치를 켭니다.
4. **OPDS 서비스 시작 → 사용**을 체크하고 아래 값을 확인합니다.
5. **설정 저장**을 누릅니다.

| 설정 항목 | 처음 설치할 때 입력할 값 |
| --- | --- |
| 수신 주소 | `0.0.0.0` |
| 컨테이너 내부 포트 | `5941` |
| 앱에서 접속할 기본 URL | 비워두기 |
| 페이지당 목록 항목 수 | `30` |
| 카탈로그 제목 | `BookOasis Audiobooks` 또는 원하는 이름 |

휴대폰 브라우저에서 `http://서버주소:5941/opds`를 열어 보세요. BookOasis 계정으로 인증한 뒤 XML 형식의 목록이 보이면 서버 준비가 끝난 것입니다.

## 3. Android 앱 설치

**[Readest BookOasis APK 다운로드](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b6/Readest-BookOasis-0.12.16-b6-arm64.apk)** 후 휴대폰·태블릿에서 엽니다. Android가 해당 브라우저·파일 앱의 설치 허용을 요구하면 허용한 뒤 설치합니다.

앱 이름은 **Readest BookOasis**입니다. 공식 Readest가 설치되어 있어도 함께 설치할 수 있습니다. 기존 Readest BookOasis를 사용 중이면 삭제하지 않고 APK를 열어 업데이트합니다.

## 4. 앱에 내 서버 등록

1. **Readest BookOasis**를 실행합니다.
2. 서재 위쪽 **`+` → 온라인 라이브러리**를 엽니다. 기기에 따라 **OPDS 카탈로그**로 표시될 수 있습니다.
3. **내 카탈로그 → 카탈로그 추가**를 누릅니다.
4. 다음 내용을 입력하고 **카탈로그 추가**를 누릅니다.

| 앱 입력 항목 | 입력 예시 |
| --- | --- |
| 카탈로그 이름 | `내 BookOasis 오디오북` |
| OPDS URL | `http://서버주소:5941/opds` |
| 사용자 이름 | BookOasis에 로그인할 때 쓰는 사용자 이름 |
| 비밀번호 | 해당 BookOasis 계정의 비밀번호 |

예를 들어 집 안 서버 주소가 `192.168.1.10`이면 `http://192.168.1.10:5941/opds`를 입력합니다. 휴대폰과 서버가 같은 네트워크에 있어야 이 주소로 접속할 수 있습니다.

앱의 사용자 이름·비밀번호 칸에 ‘선택 사항’이라고 표시되어도 **이 플러그인에 연결할 때는 둘 다 입력해야 합니다.** OPDS 연결에 Readest 계정이나 Google 로그인은 필요하지 않습니다.

## 5. 책 고르고 듣기

1. **내 카탈로그**에서 방금 등록한 서버를 엽니다.
2. 카테고리를 고르면 책 표지와 제목이 나옵니다.
3. 원하는 책을 열고 **재생**을 누릅니다.
4. 여러 회차로 된 책은 **회차 목록**에서 듣고 싶은 회차를 선택합니다. 한 파일로 된 책은 바로 플레이어로 이동합니다.
5. 재생 중 **회차 목록**, 이전·다음 버튼으로 회차를 바꿀 수 있습니다. 다시 열 때는 **재개**로 이어듣습니다.

정렬 메뉴에서 **제목 가나다순 / 제목 역순 / 최신 추가순 / 오래된 추가순 / 최근 수정순**을 고를 수 있습니다. 재생 시간과 탐색 막대는 현재 회차 기준입니다.

## 6. 자동 동기화와 전체 진행률

앱 b6에서 등록한 OPDS 서버를 열고 오디오북을 재생하면 해당 BookOasis 계정에 재생목록과 위치를 저장합니다. 같은 서버·같은 BookOasis 계정을 쓰는 다른 기기에서도 이어듣습니다. **동기화 버튼을 누르거나 Google 계정으로 로그인할 필요가 없습니다.** 서재의 작은 동기화 아이콘으로 상태를 확인합니다.

- 앱을 열거나 화면으로 돌아올 때, 네트워크가 복구될 때, 화면이 활성 상태인 동안 주기적으로 동기화합니다. 오프라인 변경은 연결이 돌아오면 재시도합니다.
- BookOasis 웹에서 들은 회차와 위치도 앱으로 가져옵니다. 앱에서 들은 기록은 웹의 최근 들은 오디오북과 이어듣기에 반영됩니다. 여러 기기를 동시에 재생하면 마지막으로 저장된 위치를 확인하세요.
- 플레이어와 서재에서 **현재 회차 / 전체 회차**, 전체 진행률과 남은 시간을 표시합니다. 재생 막대는 현재 회차 기준입니다.
- 회차 길이를 모두 확인하기 전에는 **회차 기준 약 % / 전체 시간 확인 전**으로 표시합니다. 전체 위치는 건너뛴 회차까지 실제로 청취했다는 뜻은 아닙니다.

BookOasis OPDS의 재생목록·위치는 **내 BookOasis 서버**로 동기화하며, 이 자료를 Readest 공식 클라우드에 업로드하지 않습니다. 일반 전자책의 기존 Readest 클라우드 기능은 별개입니다.

## 7. 웹 홈에 진행률 위젯 추가

**홈 화면의 ‘배치 잠금’을 해제해야 ‘위젯 추가’가 보입니다.** 설정 페이지에서 모드만 켜면 바로 나타나는 메뉴가 아닙니다.

1. BookOasis의 **오디오북**을 선택한 상태에서 **환경설정 → 내 설정**을 엽니다.
2. **화면 및 뷰어 개인화 설정** 맨 아래의 **홈 화면을 플러그인 배치 모드로 전환**을 체크하고, 오른쪽 아래 **설정 저장**을 누릅니다. 이미 체크되어 있으면 그대로 저장합니다.
3. 설정에서 나와 **오디오북 홈 화면**으로 돌아갑니다. ‘최근 들은 오디오북’, ‘신규 추가 오디오북’ 등이 나오는 화면입니다. 메뉴가 접혀 있으면 왼쪽 위 **☰**를 열어 홈으로 이동합니다.
4. 홈을 **맨 아래까지 스크롤**합니다. 마지막 위젯 아래, 저작권 문구 위 **오른쪽**에 있는 **🔒 배치 잠금** 버튼을 누릅니다.
5. 버튼 글자가 **배치 편집 중**으로 바뀌면, 그 아래에 **+ 위젯 추가:**와 추가할 수 있는 위젯 이름 버튼들이 나타납니다.
6. 그중 **오디오북 청취 진행률** 버튼을 누릅니다. 홈에 위젯이 추가되고 배치는 자동 저장됩니다.
7. 위치를 바꾸려면 편집 상태에서 위젯을 원하는 곳으로 드래그합니다. 끝나면 아래의 **배치 편집 중** 버튼을 다시 눌러 **배치 잠금**으로 돌려놓습니다.

위젯에는 현재 회차, 전체 진행률, 전체 길이와 남은 시간이 표시됩니다. 제목을 누르면 웹 플레이어에서 이어듣고, 화면을 보고 있는 동안 30초 간격으로 갱신됩니다. 본인 계정의 기록과 접근 가능한 책만 표시합니다.

**추가 목록에 이름이 없을 때:** 홈에 이미 **오디오북 청취 진행률** 위젯이 있는지 먼저 확인하세요. 이미 추가한 위젯은 추가 목록에 다시 나오지 않습니다. 홈에도 없다면 플러그인 0.5.2 설치·활성화와 컨테이너 재시작을 확인한 뒤 페이지를 새로고침합니다. 위젯은 **일반 도서가 아닌 오디오북 홈**에서 제공합니다.

**기존 ‘현재 읽는 중’ 카드의 98% 표시는 이 업데이트로 고쳐지지 않습니다.** 이 플러그인은 본체 코드를 수정하지 않고 별도 위젯에서 전체 진행률을 계산합니다. 기존 카드가 혼동된다면 배치 편집 상태에서 **독서 인사이트**를 제거할 수 있지만, 연속 독서·연간 목표·장르 통계도 함께 숨겨집니다.

## 집 밖에서도 접속하려면

휴대폰에서 접근할 수 있는 외부 주소가 필요합니다. HTTPS 리버스 프록시를 사용한다면 OPDS용 도메인을 서버의 **5941 포트**로 연결하고, 앱에는 `https://audio.example.com/opds` 형태로 등록합니다.

이때 플러그인의 **앱에서 접속할 기본 URL**에는 `https://audio.example.com`을 입력합니다. 이 설정에는 끝에 `/opds`를 붙이지 않습니다. 기존 BookOasis 웹 화면만 외부에 연결되어 있다면 OPDS용 연결도 추가해야 합니다. [주소와 포트 설정 자세히 보기](docs/INSTALL.ko.md#외부에서-접속하기)

## 잘 안 될 때

| 증상 | 확인할 것 |
| --- | --- |
| 오디오북 OPDS가 설정에 안 보임 | 파일 위치가 `plugins/metadata/audiobook_opds/`인지 확인하고 BookOasis 재시작 |
| 주소에 연결할 수 없음 | `5941:5941`, OPDS 서비스 사용 체크, 서버 주소와 방화벽 확인 |
| 인증 실패 | BookOasis 계정·비밀번호 확인. 기본 비밀번호 상태라면 BookOasis에서 변경 후 사용 |
| 카테고리가 비어 있음 | BookOasis의 오디오북 등록 상태와 해당 계정의 라이브러리 접근 권한 확인 |
| 책은 나오는데 재생 안 됨 | 서버에서 원본 파일을 읽을 수 있는지 확인하고 Readest BookOasis 앱으로 재생 |

## 소스와 라이선스

이 프로젝트는 [BookOasis](https://github.com/leeyj/BookOasis_stable)와 [Readest](https://github.com/readest/readest)의 비공식 확장입니다. 플러그인과 앱 수정판은 AGPL-3.0 라이선스를 따르며, 원본 고지를 유지합니다. 앱 APK와 해당 버전의 전체 수정 소스를 함께 제공합니다. GitHub가 자동 생성하는 `Source code` ZIP은 이 배포 저장소이고, 앱 전체 소스는 릴리스의 [별도 소스 ZIP](https://github.com/hejerd/bookoasis-audiobook-opds/releases/download/v0.5.2-b6/Readest-BookOasis-0.12.16-b6-source.zip)으로 제공합니다.
